# EXAM-MASTER Web 重构

用户目标：以代码最小化为准则重构 Python Web 应用，使用 Open Design 重做网页，补齐基础题库管理。已确认保留登录、多用户学习记录及现有学习模式，合并重复实现。

## 现状

- Flask + SQLite + Jinja；Web 源码 7,624 行，6,607 非空行。
- app.py 1,494 行；浏览页 2,101 行；公共 CSS 1,705 行。
- 原始 CSV 有 881 道题，481 单选、400 多选，无重复题号。
- CSV 仅启动时导入；缺少网页题目 CRUD、上传、导出。
- 定时脚本在 templates 中，却通过 static URL 引用；多种模式重复判题、连接数据库、渲染列表。

## 决策

继续使用 Flask + sqlite3 + Jinja + 原生 CSS/少量 JavaScript。拆成 app.py（页面与学习流程）和 db.py（数据库、题目格式、CSV）；共享模板和样式。独立 SPA 增加 API/客户端状态与构建代码；改用 Django 需要重做既有数据库和学习逻辑，均不符合本次最小化目标。

- 不引入 ORM、前端构建工具或额外安全子系统。
- Android 目录不在开发范围内，网页去掉 APK 入口。
- 保留已有用户、密码散列、历史、收藏、顺序进度和考试记录；只添加题目解析与考试快照字段。
- 不压缩可读性来凑行数；目标 Web 源码减少至少 50%。

## 功能

- 题目：题号、题干、A–E、答案、解析、题型、分类、难度；新增/编辑/删除、关键词和组合筛选、分页。
- CSV：兼容现有中文列名；UTF-8 BOM 导出；同题号更新、新题号新增；明确显示覆盖语义；结构错误文件不部分写入；题干、答案或选项不完整的内容可导入为待补全题，练习和考试跳过。
- 题型：单选、多选、判断、填空；多选忽略选项顺序，填空保留文字顺序。
- 练习：随机未答、顺序续答、错题复习；正确答案与解析；收藏与标签。
- 学习：答题历史、统计、重置个人记录；多用户数据分开显示。
- 考试：抽题数量、可选限时、答题草稿、倒计时、提交与可重读结果；重复提交不重复写记录。

## 前端

通过 Open Design 桌面应用生成原生 HTML/CSS/JS 原型，主任务提取设计并接入真实 Flask 数据。桌面侧栏、移动折叠导航；浅色纸张、墨色文字、单一主色；概览、题库、专注练习、考试、学习记录和登录。页面统计只能来自真实数据。

## 验收

使用临时 SQLite 数据库测试题目生命周期、CSV 往返/回滚、四类判题、顺序续答、收藏/错题、考试重复提交与持久化、旧库升级。启动网页实际走通导入/管理/练习/考试，并检查桌面与窄屏显示。比较重构前后 Web 源码行数，确认 Android 无变化。
